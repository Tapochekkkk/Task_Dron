# TaskDron

Task Dron

Демонстративный проект функции Interact в UE5.6 на Blueprints.

Управление: отсутсвует.

Использование: На карте уже расставлены объекты.

BP_Camera:

Target - объект к которому цепляется камера

Radius - растояние от объекта

Height - высота на которой находится камера

Speed - скорость вращения камеры

Требования: Наличие UE5.6 FAQ

Зачем вы разработали этот проект?

Выполнение тестового задания

Задача: Создать дрона, который будет летать по траектории во круг машины и сохранять скриншоты
